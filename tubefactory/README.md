# TubeFactory — фабрика YouTube-видео на ИИ

Софт делает видео «под ключ» по одной кнопке:

**идея / видео конкурента → сценарий → персонажи → озвучка → картинки → превью → монтаж с субтитрами → загрузка на YouTube**

Все тексты и картинки идут через **один ключ OpenRouter** (Claude, GPT, Gemini и модели картинок). Озвучка по умолчанию бесплатная (Microsoft Edge TTS), можно подключить OpenAI TTS или ElevenLabs. Каналов может быть сколько угодно (хоть 10): у каждого своя ниша, стиль, голос и автопилот.

## Компания из ИИ-агентов

Софт устроен как YouTube-компания: у каждого сотрудника своя модель OpenRouter, лучшая в своём деле. Модели меняются на странице **🏢 Компания**, там же видно, сколько потратил каждый агент, и лента «кто что сделал».

| Отдел | Сотрудник | Модель по умолчанию | Работа |
|---|---|---|---|
| Руководство | 👔 Директор | `anthropic/claude-sonnet-4.5` | По отчёту аналитика и идеям исследователя решает, что снимать, и даёт указания команде |
| Контент | 🔎 Исследователь ниш и трендов | `perplexity/sonar-pro` (ищет в интернете) | Свежие тренды и темы, ниши |
| | 🧪 Аналитик референсов | `google/gemini-2.5-pro` | Разбор видео конкурентов |
| | ✍️ Сценарист | `anthropic/claude-sonnet-4.5` | Сценарий с хуком и удержанием |
| | 🧐 Шеф-редактор | `openai/gpt-5` | Оценивает сценарий; ниже 8/10 отправляет на доработку |
| Продакшн | 🎨 Арт-директор | `google/gemini-2.5-pro` | Стиль-гайд, промпты кадров, движение камеры для каждой сцены |
| | 🖌 Художник | `google/gemini-2.5-flash-image` | Персонажи и кадры |
| | 🎙 Диктор | Edge / OpenAI / ElevenLabs | Озвучка |
| | 🎬 Монтажёр-аниматор | ffmpeg | Анимация кадров, монтаж, субтитры, музыка |
| | 🖼 Дизайнер баннеров | `google/gemini-2.5-flash-image` | Превью |
| Рост | 📣 Маркетолог | `anthropic/claude-sonnet-4.5` | 5 вариантов заголовка, описание, концепция превью, закреплённый комментарий |
| | 🏷 SEO-теггер | `perplexity/sonar` (ищет в интернете) | Теги и хэштеги по реальным запросам |
| | 🚀 Публикатор | YouTube API | Загрузка в лучшее время |
| | 📊 Аналитик канала | `google/gemini-2.5-flash` | Каждые 6 часов собирает просмотры, находит лучшее время заливки и что заходит |

**Как это работает на автопилоте:** раз в минуту софт проверяет каналы. Аналитик обновляет статистику, затем проходит планёрка: исследователь приносит тренды, директор выбирает тему, после чего сценарист, редактор, арт-директор, маркетолог, теггер, художник, диктор и монтажёр делают видео, а публикатор ставит его на лучшее время. Планёрку можно запустить и вручную: кнопка **«Директор, что снимаем?»**.

## Что умеет

| Раздел | Что делает |
|---|---|
| **AI-сценарист** | Вставляете ссылку на видео конкурента с миллионами просмотров — софт скачивает транскрипт (yt-dlp), разбирает, почему видео зашло, и предлагает идеи. Кнопка «Создать и запустить». |
| **Проект** | Этапы с прогрессом: Сценарий → Персонажи → Озвучка → Картинки → Превью → Сборка → YouTube. Одна кнопка «Запустить генерацию». Любой этап можно перезапустить. Если что-то упало, при повторном запуске софт продолжит с места ошибки. |
| **Сцены** | Сетка кадров: правка текста озвучки и промпта, «Перерисовать», «Переозвучить», прослушивание. |
| **Персонажи** | Для героя сначала рисуется референс, и он передаётся в каждую сцену, поэтому герой выглядит одинаково во всём видео. |
| **Видео и YouTube** | Плеер, скачивание MP4, превью с крупным текстом, заголовок, описание, теги, загрузка. |
| **Каналы** | Ниша, язык, голос, стиль картинок, количество сцен, ритм (спокойный: кадр на 2-4 фразы, динамичный: кадр на каждую фразу), формат 16:9 или Shorts 9:16. |
| **Автопилот** | Раз в минуту проверяет каналы: если сегодня сделано меньше видео, чем «Видео в день», ИИ придумывает новую идею для ниши (не повторяя старые), делает видео и ставит его на отложенную публикацию в заданный час. |
| **Очередь** | Проекты делаются по одному, картинки внутри проекта генерируются параллельно. |
| **Поиск ниш** | ИИ предлагает ниши с RPM, конкуренцией и примерами заголовков. Кнопка «Создать канал с этой нишей». |

Монтаж делается через ffmpeg: каждая картинка держится на экране ровно столько, сколько длится её фраза, с плавным зумом или панорамой (эффект Ken Burns). Субтитры привязаны к словам, можно добавить фоновую музыку.

## Установка

Нужны **Python 3.10+** и **ffmpeg**.

```bash
# macOS
brew install ffmpeg python
# Windows: winget install Gyan.FFmpeg Python.Python.3.12
# Ubuntu: sudo apt install ffmpeg python3-pip

cd tubefactory
# Windows: просто дважды кликните start.bat
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run.py                    # откроется http://127.0.0.1:8000
```

На Windows команда `python` может открывать Microsoft Store — тогда используйте `py run.py` или `start.bat`.

1. **Настройки** → вставьте ключ OpenRouter (https://openrouter.ai/keys) → «Сохранить». Без ключа софт работает в демо-режиме: вместо ИИ подставляются заглушки, так что весь цикл можно проверить бесплатно.
2. **Каналы** → «+ Канал» → ниша, стиль, голос.
3. **AI-сценарист** → ссылка на видео конкурента → «Разбери референс» → «Создать и запустить».

### Модели (меняются в Настройках, кнопка «Загрузить список моделей»)

- Сценарий: `anthropic/claude-sonnet-4.5` (лучше всех держит удержание и структуру), дешевле: `google/gemini-2.5-flash`.
- Картинки: `google/gemini-2.5-flash-image` (Nano Banana) хорошо сохраняет персонажа по референсу. Можно выбрать любую модель OpenRouter с выходом `image`.

Примерная стоимость 10-минутного видео на 50 кадров: картинки около $2, сценарий около $0.1–0.3, озвучка Edge бесплатна. Точные цены смотрите на openrouter.ai/models.

## YouTube: подключение каналов

1. https://console.cloud.google.com → создайте проект → **APIs & Services → Library** → включите **YouTube Data API v3**.
2. **OAuth consent screen**: тип External, добавьте свой Gmail в Test users.
3. **Credentials → Create credentials → OAuth client ID → Desktop app** → скачайте JSON и сохраните как `tubefactory/data/client_secret.json`.
4. В софте: **Каналы → «Подключить YouTube»**. Откроется браузер, войдите и выберите нужный канал (бренд-аккаунт). Для каждого канала токен хранится отдельно.

Ограничения YouTube API: квота по умолчанию 10 000 единиц в день, одна загрузка стоит около 1 600, то есть примерно **6 видео в день на один Google Cloud проект**. Для 10 каналов попросите увеличение квоты или заведите несколько проектов. Пока приложение не прошло проверку Google, видео, загруженные через API, могут оставаться приватными: это ограничение Google для непроверенных приложений.

## Важно про монетизацию

С июля 2025 года YouTube демонетизирует «неаутентичный» контент (inauthentic content): массовые однотипные видео по шаблону без ценности. Чтобы каналы монетизировались:
- проверяйте и правьте сценарии (вкладка «Сцены»), добавляйте свои факты и мнение;
- держите узнаваемый стиль и персонажа, а не случайные картинки;
- не копируйте чужие видео: AI-сценарист использует референс только как образец структуры;
- галочка «синтетический контент» ставится при загрузке автоматически, YouTube этого требует.

## Структура

```
tubefactory/
  run.py              запуск сервера
  app/
    server.py         HTTP API + веб-интерфейс
    pipeline.py       этапы генерации
    scenarist.py      промпты: разбор референса, идеи, сценарий, ниши
    llm.py            клиент OpenRouter (текст + картинки)
    images.py         персонажи, кадры, превью
    tts.py            озвучка (Edge / OpenAI / ElevenLabs) + тайминги слов
    video.py          ffmpeg: Ken Burns, склейка, субтитры, музыка
    youtube.py        OAuth, загрузка, превью, транскрипт референса
    jobs.py           очередь и автопилот
    storage.py        проекты и каналы (JSON-файлы в data/)
  web/                интерфейс (HTML/CSS/JS без сборки)
  data/               ваши проекты, ключи, токены (в git не попадает)
```

Настройки можно задавать и через переменные окружения: `OPENROUTER_API_KEY`, `TEXT_MODEL`, `IMAGE_MODEL`, `TTS_PROVIDER`, `DEMO_MODE=1`, `TUBEFACTORY_DATA=/путь/к/данным`.
