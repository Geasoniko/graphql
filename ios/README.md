# 📱 Наша галерея — приложение для iPhone

Это приложение открывает ту же игру, что и сайт, но умеет то, чего не умеет Safari:
**фильмы из GitHub Releases идут прямо на экране кинотеатра и синхронно с партнёром.**
Игра внутри обновляется сама — переустанавливать приложение ради обновлений игры не нужно.

Аккаунт разработчика не нужен — ставим с компьютера на Windows через бесплатную программу
**Sideloadly** с обычным Apple ID.

## Что нужно
- компьютер с Windows и кабель для iPhone;
- Apple ID владельца iPhone (лучше не основной — можно создать отдельный бесплатный);
- iTunes и iCloud **с сайта Apple**, не из Microsoft Store:
  - iTunes: https://www.apple.com/itunes/download/win64
  - iCloud: https://support.apple.com/HT204283
- Sideloadly: https://sideloadly.io

## Установка (один раз ~10 минут)
1. Скачайте приложение: **https://github.com/Geasoniko/graphql/releases/download/ios-app/NashaGalereya.ipa**
2. Подключите iPhone кабелем к компьютеру, на iPhone нажмите **«Доверять этому компьютеру»**.
3. Откройте **Sideloadly**: вверху должен появиться ваш iPhone.
4. Перетащите `NashaGalereya.ipa` в окно Sideloadly, в поле **Apple account** впишите Apple ID → **Start**.
   Введите пароль Apple ID (и код, если придёт).
5. На iPhone:
   - **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**;
   - на iOS 16 и новее: **Настройки → Конфиденциальность и безопасность → Режим разработчика → Вкл**,
     iPhone перезагрузится, после этого подтвердите «Включить».
6. Откройте **«Наша галерея»** на экране «Домой» 💕 При первом нажатии на 🎤 разрешите микрофон.

## Раз в 7 дней
С бесплатным Apple ID Apple разрешает приложению работать 7 дней. Потом оно перестанет открываться —
просто повторите шаг 4 (подключить iPhone, перетащить тот же `.ipa`, Start). Ваши монеты и вещи сохранятся.

## Как это устроено
- `NashaGalereya/GameViewController.swift` — полноэкранный WebView с игрой, разрешение на микрофон.
- `NashaGalereya/GameSchemeHandler.swift` — отдаёт игру по адресу `nashagame://game/…`, загружая файлы
  с сайта, а фильмы `films/*.mp4` — из GitHub Releases с правильной пометкой «видео» и поддержкой перемотки.
- Приложение собирает GitHub (`.github/workflows/ios.yml`) на своём Mac; готовый `.ipa` появляется
  в релизе **ios-app** после каждого изменения в папке `ios/`.
