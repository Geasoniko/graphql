# Наша галерея 💕 — 3D-игра для двоих

Девушка и парень гуляют по 3D-миру: галерея с вашими фото из Google Drive, магазин, кинотеатр.
Работает в браузере на ноутбуке и на телефоне.

**Играть:** https://geasoniko.github.io/graphql/game/
(в репозитории: Settings → Pages → Branch `main`, папка `/ (root)`)

## Что есть в игре
- 👧 / 👦 выбор персонажа, игра вдвоём по коду комнаты или ссылке-приглашению
- 🏛️ **Холл** — отсюда всё начинается
- 🖼️ **Галерея** — несколько залов подряд (розовый, лавандовый, мятный, персиковый…).
  Сколько фото — столько рамок, залы добавляются сами. Рамки разных размеров: большие, средние, маленькие парами.
- 🪑 **Сесть** — на скамейки в залах и диваны в холле
- 🛍️ **Магазин** — цветы (букеты 8, 16, 25, 51, 101, 301 роза), одежда, смартфоны, сумки
- 🪙 **Монеты** — у девушки 5, у парня 99 999 😄
- 🎒 **Мои вещи** — всё купленное попадает сюда. Можно: взять в руку, надеть, подарить партнёру 🎁,
  положить в сумку 👜 и достать обратно, съесть попкорн 🍿
- 🎟️ **Касса** — выбор фильма и мест на схеме зала, билет можно посмотреть
- 🎬 **Кинотеатр** — после покупки в зале появляются зрители. Зайдите, нажмите «💺 Моё место» —
  персонаж сядет, если партнёр с билетом — игра ждёт его, потом **3-2-1** и фильм начинается
- 💃 эмоции: Танец 1, Танец 2, Вальс и Поцелуй (вдвоём), Привет, Сердечки

## Фото из папки Google Drive (автоматически)

1. Положите все фото в одну папку Google Drive.
2. Папка → **Поделиться** → **Все, у кого есть ссылка** (тогда и все фото внутри открыты).
3. Откройте https://script.google.com → **Создать проект** → удалите всё и вставьте:

   ```js
   var FOLDER_ID = 'ВСТАВЬТЕ_ID_ПАПКИ'; // это часть ссылки на папку после /folders/

   function doGet() {
     var files = DriveApp.getFolderById(FOLDER_ID).getFiles();
     var out = [];
     while (files.hasNext()) {
       var f = files.next();
       if (f.getMimeType().indexOf('image/') === 0) out.push({ id: f.getId(), t: f.getDateCreated().getTime() });
     }
     out.sort(function (a, b) { return a.t - b.t; });
     return ContentService.createTextOutput(JSON.stringify(out)).setMimeType(ContentService.MimeType.JSON);
   }
   ```

4. **Начать развёртывание** → **Новое развёртывание** → тип **Веб-приложение**
   → «Запуск от имени»: **Я**, «Доступ»: **Все** → **Начать развёртывание** → разрешите доступ.
5. Скопируйте ссылку вида `https://script.google.com/macros/s/…/exec`.
6. В `game/photos.js` вставьте:
   - `driveFolder: 'ссылка на папку'`
   - `driveListUrl: 'ссылка …/exec'`

Готово: добавили фото в папку → обновили игру → фото уже на стенах. 🎉

**Без скрипта** тоже можно: вставьте ссылки на отдельные фото в `photos: [...]`
или прямо в игре кнопкой 🖼️ (по одной ссылке на строку). Доступ у фото — «Все, у кого есть ссылка».

## Фильмы для кинотеатра
1. Загрузите фильм (mp4) в Google Drive → «Поделиться» → «Все, у кого есть ссылка» → скопируйте ссылку.
2. В `game/photos.js` в `movies` вставьте название и ссылку:
   ```js
   movies: [
     { title: 'Титаник', url: 'https://drive.google.com/file/d/…/view' },
     { title: 'Фильм 2', url: '' },
     { title: 'Фильм 3', url: '' },
   ],
   ```
3. Если ссылки нет — в кино появится кнопка «📁 Выбрать видео с устройства» (файл с телефона/ноутбука).

Фильм из Google Drive запускается кнопкой ▶ в плеере после отсчёта 3-2-1. Кнопка «⛶ На весь экран» — для телефона.

## Управление
| | Ноутбук | Телефон |
|---|---|---|
| Ходить | WASD / стрелки, Shift — бег | джойстик слева |
| Камера | зажать мышь, колесо — зум | провести пальцем, щипок — зум |
| Эмоции | клавиши 1–7 | кнопки справа |
| Действие рядом (магазин, касса, фото, место) | E или кнопка | кнопка над джойстиком |
| Мои вещи | I или 🎒 | 🎒 |

## Файлы
- `index.html`, `style.css` — страница и оформление
- `game.js` — игра: деньги, вещи, кино, игра вдвоём
- `world.js` — 3D-мир: холл, магазин, касса, залы галереи, кинотеатр
- `characters.js` — персонажи и их движения
- `items.js` — товары и цены
- `audio.js` — музыка и звуки
- `photos.js` — **ваши настройки** (фото, папка, фильмы)
- `vendor/` — three.js и PeerJS
