# Наша галерея 💕 — 3D-игра для двоих

Девушка и парень гуляют по 3D-галерее с вашими фото из Google Drive.
Работает в браузере на ноутбуке и на телефоне, ничего устанавливать не нужно.

## Возможности
- 👧 / 👦 Выбор персонажа, вид от третьего лица
- 💌 Игра вдвоём: один создаёт комнату, второй заходит по коду (или по ссылке-приглашению)
- 🖼️ Фото на стенах — ссылки из Google Drive или фото с телефона/ноутбука
- Кнопки-эмодзи: 🕺 Танец 1, 💃 Танец 2, 💞 Вальс (вдвоём), 💋 Поцелуй (вдвоём), 👋 Привет, ❤️ Сердечки
- 🎵 Музыка к танцам и вальсу

## Как запустить
Игру нужно открыть через веб-сервер (не двойным кликом по файлу):

**Вариант 1 — GitHub Pages (бесплатно, удобно для телефона):**
Settings → Pages → Source: `Deploy from a branch` → выберите ветку и папку `/ (root)`.
Игра будет по адресу `https://<ваш-логин>.github.io/<репозиторий>/game/`.

**Вариант 2 — локально:** в папке `game` выполните `python3 -m http.server 8000`
и откройте http://localhost:8000.

## Как добавить фото из Google Drive
1. В Google Drive откройте фото → **Поделиться** → **Все, у кого есть ссылка** → **Копировать ссылку**.
2. В игре нажмите 🖼️ вверху справа, вставьте ссылки (по одной на строку) → «Повесить в галерею».
   Партнёр увидит те же фото.
3. Чтобы фото были всегда — вставьте ссылки в `photos.js` (массив `photos`).

Фото из `photos.js` висят в галерее всегда, сами. Если Google не отдаёт картинку напрямую, игра загружает её через бесплатный прокси wsrv.nl.

Можно вставить ссылку на целую **папку**, если указать `driveApiKey` в `photos.js`
(ключ Google Cloud с включённым Drive API; папка тоже должна быть открыта по ссылке).

## Управление
| | Ноутбук | Телефон |
|---|---|---|
| Ходить | WASD / стрелки, Shift — бег | джойстик слева |
| Камера | зажать мышь и вести, колесо — зум | провести пальцем, щипок — зум |
| Эмоции | клавиши 1–6 или кнопки | кнопки справа |
| Фото | E или клик по фото | нажать на фото |

Вальс и поцелуй — совместные: подойдите к партнёру и нажмите кнопку. Чтобы закончить — просто идите.

## Как это устроено
- 3D: [three.js](https://threejs.org) (лежит в `vendor/`), персонажи и анимации собраны из простых фигур в коде.
- Игра вдвоём: WebRTC через [PeerJS](https://peerjs.com) (бесплатный публичный сервер для соединения).
