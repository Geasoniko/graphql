# 🎬 Фильмы для кинотеатра

Положите сюда файлы **.mp4** ровно с такими именами:

| Фильм | Имя файла |
|---|---|
| Ла-Ла Ленд | `lalaland.mp4` |
| История игрушек 5 | `toystory5.mp4` |
| Миньоны и монстры | `minions-monsters.mp4` |

⚠️ GitHub не принимает в репозиторий файлы больше **100 МБ** (а через сайт — больше **25 МБ**).
Полный фильм обычно весит больше — тогда загрузите его в **Releases** (до 2 ГБ на файл),
инструкция в `game/README.md` → «Фильмы для кинотеатра». Игра найдёт фильм в любом из двух мест.
